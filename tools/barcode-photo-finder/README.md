# پیدا کردن عکس کالا از روی بارکد ← اکسل با عکس

نسخهٔ اسکریپتیِ اسکیل «عکس قفسه ← اکسل پلانوگرام». به‌جای خواندن عکس قفسه، **بارکد و نام هر
کالا را از فایل اکسل** برمی‌دارد، از همان منابع اسکیل عکس واقعی کالا را پیدا می‌کند و یک اکسل
راست‌به‌چپ می‌سازد که عکس هر کالا داخل ردیف خودش است.

> سایت‌های ایرانی از سرورهای خارج از ایران باز نمی‌شوند؛ اسکریپت را **روی کامپیوتری در ایران** اجرا کنید.

## نصب (یک بار)
1. پایتون ۳.۹ یا بالاتر (در ویندوز هنگام نصب تیک «Add python to PATH» را بزنید).
2. در همین پوشه:
   ```bash
   pip install -r requirements.txt
   ```

## اجرا
ویندوز: فایل اکسل را کنار `run.bat` بگذارید و روی `run.bat` دابل‌کلیک کنید (یا فایل اکسل را روی آن بکشید). یا:
```bash
python find_product_photos.py products-photo-2026-10-28.xlsx
```
اول با ۲۰ کالا امتحان کنید:
```bash
python find_product_photos.py products-photo-2026-10-28.xlsx --limit 20
```

خروجی‌ها کنار فایل ورودی:
| فایل | محتوا |
|---|---|
| `<نام>-with-photos.xlsx` | همهٔ ستون‌های ورودی + وضعیت عکس، اطمینان، منبع، عنوان در منبع، لینک محصول، یادداشت، **تصویر کالا**؛ ستون «آدرس عکس اصلی» پر می‌شود؛ شیت «راهنما» با خلاصه |
| `<نام>-with-photos_images/` | عکس‌های اصلی با نام `بارکد - نام کالا` |
| `<نام>-with-photos_log.csv` | منبع و یادداشت هر ردیف |
| `<نام>-with-photos_cache.json` | پیشرفت کار؛ اگر اجرا قطع شد (Ctrl+C)، دوباره همان دستور را بزنید تا از همان‌جا ادامه دهد |

## روش جستجو (همان قواعد اسکیل)
برای هر بارکد به ترتیب:
1. **daychi.com** — آدرس `/products/<بارکد>`؛ آدرس خودِ بارکد است ← تطبیق دقیق.
2. **hamekara.com** — API جستجو با فیلد `barcode` ← فقط بارکد دقیقاً برابر.
3. **rojashop.com** — متن «بارکد : …» در صفحهٔ محصول (آرایشی‌بهداشتی).
4. **Open Food Facts** — پایگاه جهانی بارکد.
5. **دیجی‌کالا** و 6. **ترب** — جستجو با نام کالا؛ فقط وقتی پذیرفته می‌شود که نام شبیه باشد و حجم/وزن
   (گرم، کیلو، میلی‌لیتر، لیتر، عدد) مغایرت نداشته باشد.

سطح اطمینان: **بالا** = منبع همین بارکد را به محصول وصل کرده و نام هم می‌خواند ·
**متوسط** = بارکد دقیق ولی نام متفاوت، یا تطبیق قوی نام + حجم · **پایین** = فقط شباهت نسبی نام ·
**پیدا نشد** = عکس دستی لازم است. هیچ عکسی ساخته یا حدس زده نمی‌شود.

بین درخواست‌ها مکث می‌شود (`--delay`، پیش‌فرض ۱٫۵ تا ۳ ثانیه). اگر سایتی 403/429 یا کپچا بدهد،
آن سایت تا آخر همان اجرا کنار گذاشته می‌شود (کپچا دور زده نمی‌شود). ۸۰۰ کالا حدوداً ۱ تا ۲ ساعت طول می‌کشد.

## گزینه‌ها
| گزینه | کاربرد |
|---|---|
| `-o out.xlsx` | نام فایل خروجی |
| `--limit 50` / `--start 100` | تعداد کالا در این اجرا / شروع از ردیف |
| `--sources daychi,digikala` | انتخاب و ترتیب منابع (`daychi,hamekara,rojashop,off,digikala,torob`) |
| `--retry-missing` | «پیدا نشد»های قبلی دوباره جستجو شوند |
| `--min-score 0.7` | سخت‌گیری بیشتر در تطبیق نام (پیش‌فرض 0.6) |
| `--cutout` | حذف پس‌زمینه مثل اسکیل (اول: `pip install "rembg[cpu]" scipy numpy`؛ بستهٔ سفید: `--cutout-model u2net`) |
| `--barcode-col` / `--name-col` / `--sheet` | اگر نام ستون‌ها یا شیت فرق دارد |
| `--thumb 150` | اندازهٔ عکس داخل اکسل |
| `-v` | نمایش خطاهای شبکه |
