# داران‌ایکس — سیستم یکپارچه مدیریت فرآیند

> «همه چیز سر جای خودش»

یک دفتر مرکزی دیجیتال برای شرکت داران‌ایکس؛ مشتری‌ها، پروژه‌ها، کالای انبار،
فاکتورها و حساب‌وکتاب — همه در یک نرم‌افزار واحد. این مخزن پیاده‌سازی نقشه‌راهِ
سند طراحی (`DaranX_System_Blueprint`) است.

## معماری

- **مونولیت ماژولار** — یک نرم‌افزار واحد، مرتب و بخش‌بندی‌شده.
- **سه لایه:** نمایش (React) ← منطق (سرویس‌ها/روت‌ها) ← داده (SQLAlchemy/DB).
- **شش بخش با مرز مشخص:** مشتری (CRM)، پروژه/فعالیت، انبار، فاکتور، حسابداری،
  پشتیبانی. هر بخش فقط کار خودش را می‌کند و از راه مشخص با بقیه حرف می‌زند.
- **موضوع‌های عرضی:** دسترسی و امنیت (RBAC + JWT)، و ثبت رویدادها (audit).

## استک فنی

| لایه      | فناوری                                   |
| --------- | ---------------------------------------- |
| بک‌اند     | Python + FastAPI                         |
| دیتابیس   | PostgreSQL (پیش‌فرض توسعه: SQLite)        |
| فرانت‌اند  | React (Vite) با پشتیبانی کامل فارسی و RTL |
| دسترسی    | نقش‌محور (RBAC): مدیر، فروش، فنی، انباردار، حسابدار |

## راه‌اندازی سریع (ویندوز) — تک‌کلیکی

اگر ویندوز داری، لازم نیست دستورها را دستی بزنی. فقط **Python 3.11+** و
**Node.js 18+** را نصب کن (موقع نصب Python تیک «Add python.exe to PATH» را بزن)،
بعد روی فایل **`start.bat`** در ریشهٔ پروژه دابل‌کلیک کن.

این اسکریپت خودش پیش‌نیازها را چک می‌کند، محیط مجازی و پکیج‌ها را نصب می‌کند،
حساب مدیر اولیه را می‌سازد، هر دو سرور (بک‌اند + فرانت‌اند) را در دو پنجرهٔ جدا
بالا می‌آورد و مرورگر را روی <http://localhost:5173> باز می‌کند.

- ورود: شماره `09120000000` / رمز `admin1234` — بعد از اولین ورود عوضش کن.
- برای توقف: دو پنجرهٔ سروری که باز شده را ببند.

برای راه‌اندازی دستی (یا سیستم‌های غیرویندوزی)، مراحل زیر را دنبال کن.

## راه‌اندازی بک‌اند

پیش‌نیاز: Python 3.12+ (این پروژه روی 3.14 بوت‌استرپ شده).

```bash
cd backend
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/Mac:
# source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env          # مقادیر را تنظیم کنید (به‌ویژه SECRET_KEY)
python -m app.seed            # ساخت حساب مدیر اولیه
uvicorn app.main:app --reload # اجرا روی http://localhost:8000
```

- مستندات تعاملی API: <http://localhost:8000/docs>
- حساب اولیه (از `.env`): شماره تماس `09120000000` / رمز `admin1234` — **بعد از
  اولین ورود عوض کنید**.

### سوییچ به PostgreSQL

فقط کافی است در `.env` مقدار `DATABASE_URL` را تغییر دهید (بدون تغییر کد):

```
DATABASE_URL=postgresql+psycopg://daranx:secret@localhost:5432/daranx
```

### تست‌ها

```bash
cd backend
pip install -r requirements-dev.txt
pytest -q
```

## راه‌اندازی فرانت‌اند

پیش‌نیاز: Node.js 18+ (روی این سیستم هنوز نصب نیست).

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173  (به بک‌اند روی 8000 پروکسی می‌شود)
```

## نقشه راه ساخت (فازبندی)

- [x] **فاز ۱ — پایه:** مدل داده، احراز هویت، کاربران و نقش‌ها.  ← *پیاده‌سازی‌شده*
- [x] **فاز ۲ — هسته:** طرف‌حساب (مشتری/تأمین‌کننده)، فعالیت، مراحل پروژه.  ← *پیاده‌سازی‌شده*
- [x] **فاز ۳ — انبار:** مدل کالا، تک‌کالا (سریال)، حرکت انبار (مقداری)، موجودی جاری.  ← *پیاده‌سازی‌شده*
- [x] **فاز ۴ — فروش و خرید:** بخش A (فروش) — هر پیش‌فاکتور/فاکتور اقلام خودش را دارد (شرح کالا/خدمت + تعداد + قیمت واحد)؛ یک فعالیت می‌تواند چند پیش‌فاکتور و چند فاکتور نهایی داشته باشد؛ تبدیل پیش‌فاکتور به فاکتور با اجازهٔ اصلاح قیمت؛ وصل به انبار و حسابداری. بخش B (خرید) — ثبت سند خرید و اقلامش از تأمین‌کننده، ورود کالا به انبار و ثبت خرج در حسابداری.  ← *پیاده‌سازی‌شده*
- [x] **فاز ۵ — حسابداری:** دفتر اسناد مالی، خلاصه‌ی دخل/خرج، و **مانده‌ی هر طرف‌حساب** (فروش به او منهای خرید از او). دسترسی خواندن: مدیر/حسابدار.  ← *پیاده‌سازی‌شده*
- [x] **فاز ۶ — ارجاعات:** ارجاع کارها بین کارمندان (فروش/فنی/انبار)؛ چرخه‌ی وضعیت ارجاع‌شده/در حال انجام/انجام‌شده با درج زمان انجام؛ ارجاع‌دهنده می‌تواند مرحله را دنبال کند. با صدور فاکتور فروش، یک ارجاع «تحویل کالای فروخته‌شده» خودکار برای انباردار ساخته می‌شود. دسترسی: همه‌ی کارمندان.  ← *پیاده‌سازی‌شده*
- [x] **فاز ۷ — داشبورد و گزارش‌ها:** نمای مدیریتی با KPIها (دخل/خرج/مانده، شمارش‌ها، ارجاعات باز)، نمودار دخل و خرج، وضعیت فاکتور/خرید، و بدهکاران/بستانکارانِ برتر. دسترسی: مدیر/حسابدار.  ← *پیاده‌سازی‌شده*
- [x] **افزودنی حسابداری — پرداخت/دریافت:** ثبت دریافت بابت فاکتور و پرداخت بابت خرید؛ دریافت جزئی (بخشی نقد، مابقی بعداً) و محاسبه‌ی خودکار وضعیت فاکتور (پرداخت‌نشده/قسمتی/پرداخت‌شده) و طلبِ وصول‌نشده.  ← *پیاده‌سازی‌شده*

> نکته: **کل مدل داده** (۱۲ جدول، شامل `party_contacts`) همین حالا در
> `backend/app/models` تعریف شده است؛ فازهای بعدی روی همین پایه فقط منطق و رابط
> کاربری هر بخش را اضافه می‌کنند.

## ساختار پوشه‌ها

```
daranx/
├── backend/
│   ├── app/
│   │   ├── main.py           # ورودی FastAPI (لایه نمایش/روت‌ها)
│   │   ├── config.py         # تنظیمات
│   │   ├── database.py       # موتور و نشست دیتابیس (لایه داده)
│   │   ├── models/           # مدل داده — هر ۱۱ جدول بلوپرینت
│   │   ├── schemas/          # DTOهای ورودی/خروجی
│   │   ├── core/             # امنیت (JWT/bcrypt) و RBAC
│   │   ├── api/              # روت‌ها: auth، users
│   │   └── seed.py           # ساخت مدیر اولیه
│   └── tests/                # تست‌های دود فاز ۱
└── frontend/                 # داربست React + RTL (login، dashboard)
```
