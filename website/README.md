# DaranX — وب‌سایت برند

> همه چیز سر جای درستش.

پایه و اساس وب‌سایت سازمانی/معرفی برند **DaranX**، ساخته‌شده بر اساس فایل
**DaranX Brand & Product Skill**. این پروژه از وب‌اپلیکیشن حسابداری (`../frontend`)
جداست و فقط برای معرفی برند، روش کار و حوزه‌های فعالیت است.

## استک فنی

- **React 18 + Vite** — هم‌راستا با استک فرانت‌اند پروژه.
- **RTL / فارسی** با فونت **Vazirmatn**.
- بدون وابستگی اضافه؛ ساختار کاملاً کامپوننت‌محور.

## راه‌اندازی

```bash
cd website
npm install
npm run dev        # http://localhost:5174
npm run build      # خروجی در dist/
npm run preview    # پیش‌نمایش نسخه build
```

> پورت روی `5174` تنظیم شده تا با فرانت‌اند حسابداری (روی `5173`) تداخل نداشته باشد.

## ساختار

```
website/
├── index.html              # RTL, meta/OG, فونت Vazirmatn
└── src/
    ├── main.jsx            # نقطه‌ی ورود
    ├── App.jsx             # چیدمان بخش‌های صفحه
    ├── data.js             # تمام محتوای برند (منبع واحد حقیقت)
    ├── styles.css          # توکن‌های پالت برند + استایل بخش‌ها
    └── components/
        ├── Logo.jsx        # نشان برند (فرم متقاطع/پیونددهنده)
        ├── Header.jsx      # ناوبری چسبان + منوی موبایل
        ├── Hero.jsx        # «همه چیز سر جای درستش»
        ├── Philosophy.jsx  # طراحی مقدم بر اجراست + باور اصلی
        ├── Method.jsx      # شناخت ← طراحی ← اجرا ← پشتیبانی
        ├── Services.jsx    # Infrastructure · Security · Intelligence
        ├── DesignLayer.jsx # Design به‌عنوان لایه‌ی مشترک + فرمول
        ├── Differentiator.jsx
        ├── Positioning.jsx # جایگاه برند (نه فقط… بلکه…)
        ├── Ventures.jsx    # PlanoGram
        ├── Contact.jsx     # فراخوان پایانی
        └── Footer.jsx
```

## قواعد محتوا

- نام برند همیشه دقیقاً `DaranX` نوشته می‌شود.
- لحن: ساده، حرفه‌ای، مطمئن، صریح — بدون اغراق تبلیغاتی.
- DaranX صرفاً فروشنده‌ی تجهیزات معرفی نمی‌شود؛ **شریک فناوری** است.
- Design یک لایه‌ی مشترک است، نه یک خدمت مستقل در کنار بقیه.
- برای PlanoGram هیچ قابلیت یا ادعای تجاری جدیدی بدون منبع اضافه نشده است.

## نکات تکمیلی (جای‌گذاری بعدی)

- مقادیر تماس در `Contact.jsx` و `Footer.jsx` موقت‌اند؛ با اطلاعات واقعی جایگزین شوند.
- نسخه‌ی رسمی لوگو در صورت وجود، جایگزین `Logo.jsx` شود (تناسبات و پالت حفظ شود).
