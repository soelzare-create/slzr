اسکرول کنید؛ هر حرکت، یک قدم.

هر فروشگاه، یک پروژه

نقشهٔ فروشگاه

نقشه را بارگذاری می‌کنید؛ هر قفسه روی آن یک کد می‌گیرد.

همهٔ قفسه‌ها روی یک نقشه

هر قفسه کد خودش را دارد؛ از ورودی تا صندوق.

هر قفسه، یک شناسنامه

گروه کالا، تعداد کالا، SKU و وزن کل روی همان قفسه.

چیدمان با Agent
