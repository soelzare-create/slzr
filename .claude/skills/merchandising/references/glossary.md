# واژه‌نامهٔ مرچندایزینگ (فارسی ↔ English)

برای نام‌گذاری مدل‌ها/فیلدها از ستون English (snake_case در کد) و برای رابط کاربری از
ستون فارسی استفاده کن. اگر اصطلاحی دو معادل فارسی رایج دارد، اولی را در UI بگذار.

## فهرست
1. مفاهیم پایه و بازیگران
2. قفسه، چیدمان و نمایش
3. اجرای میدانی (ویزیت و ممیزی)
4. برنامه‌ریزی کالا و قیمت
5. حسابداری و تجاری
6. چیدمان کل فروشگاه (پلان)

## ۱. مفاهیم پایه و بازیگران

| فارسی | English | توضیح کوتاه |
|---|---|---|
| مرچندایزینگ / بازارپردازی | Merchandising | هر فعالیتی در نقطهٔ فروش (و پشت آن) که کالای درست را در جای درست، زمان درست، تعداد درست و با قیمت درست جلوی خریدار می‌گذارد. |
| مرچندایزر / نیروی چیدمان / مسئول چیدمان | Merchandiser | فردی که در فروشگاه کالا را طبق استاندارد برند می‌چیند، کسری را پر می‌کند و گزارش می‌دهد. |
| مرچندایزینگ بصری (ویژوال) | Visual merchandising (VM) | طراحی ویترین، نور، مسیر حرکت، دیسپلی و نشانه‌گذاری برای جذب و هدایت مشتری. |
| مرچندایزینگ میدانی / اجرای خرده‌فروشی | Field merchandising / Retail execution | اجرای استانداردهای برند در قفسهٔ فروشگاه‌ها توسط تیم میدانی، با شواهد (عکس، موقعیت، چک‌لیست). |
| برند / صاحب کالا / تأمین‌کننده | Brand / Principal / Supplier / Manufacturer | کسی که کالا مال اوست و برای دیده‌شدن آن هزینه می‌کند. |
| شرکت خدمات مرچندایزینگ (آژانس) | Merchandising agency / Third-party merchandiser | پیمانکاری که نیروی میدانی را برای یک یا چند برند تأمین و مدیریت می‌کند. |
| خرده‌فروش / فروشگاه زنجیره‌ای | Retailer / Chain (Modern Trade, MT) | مالک قفسه؛ قواعد ورود کالا، جایگاه و پروموشن را تعیین می‌کند. |
| خرده‌فروشی سنتی / سوپرمارکت محلی | General / Traditional Trade (GT) | فروشگاه‌های مستقل که معمولاً از طریق پخش مویرگی تأمین می‌شوند. |
| پخش مویرگی | Capillary distribution / DSD | توزیع مستقیم به تعداد زیاد فروشگاه کوچک با ویزیتور و موزع. |
| ویزیتور | Pre-seller / Sales rep | سفارش‌گیر میدانی؛ گاهی وظایف مرچندایزینگ هم دارد. |
| نقطهٔ فروش / فروشگاه | Outlet / Store / Point of sale (POS) | واحد اصلی گزارش‌گیری میدانی. |

## ۲. قفسه، چیدمان و نمایش

| فارسی | English | توضیح کوتاه |
|---|---|---|
| پلانوگرام / نقشهٔ چیدمان | Planogram (POG) | نقشهٔ قفسه به قفسه: کدام SKU، کجا، با چند فیسینگ. |
| فیسینگ / رو | Facing | یک واحد کالا که رو به راهرو دیده می‌شود (تعداد ردیف‌های جلو). |
| قفسه / طبقه | Shelf | — |
| ماژول قفسه | Bay / Section | یک واحد عرضی قفسه (معمولاً ۱ متر یا ۱٫۲۵ متر). |
| استند / گوندولا | Fixture / Stand / Gondola | استندِ بزرگ و مستقل را «گوندولا» هم می‌گویند. |
| سرقفسه / اندکپ | End cap / Gondola end | انتهای راهرو؛ پربازدیدترین جای نمایش. |
| نمایش ثانویه | Secondary / Off-shelf display | جایگاه دوم خارج از قفسهٔ اصلی (پالت، استند، کنار صندوق). |
| هدر | Shelf header | نوار/تابلوی برند بالای قفسه. |
| شلف‌تاکر، وابلر، دنگلر، استریپ قفسه | Shelf talker, Wobbler, Dangler, Shelf strip | اقلام کوچک تبلیغاتی روی/لب قفسه. |
| اقلام تبلیغاتی نقطهٔ فروش | POSM (Point-of-Sale Materials) / POP | پوستر، استند، استاپر، یخچال برند‌دار و … |
| سهم قفسه | Share of Shelf (SoS) | سهم برند از فیسینگ یا طول قفسهٔ یک دسته‌کالا. |
| سهم منصفانه | Fair share | اینکه سهم قفسه با سهم فروش/بازار برند متناسب باشد. |
| سطح چشم (طبقهٔ طلایی) | Eye level ("eye level is buy level") | پربازدیدترین طبقه؛ بعد سطح دست، بعد پایین، بعد طبقهٔ کف. |
| بلوک‌بندی عمودی/افقی/رنگی | Vertical / Horizontal / Color blocking | چیدن یک برند/دسته به‌صورت بلوک یکپارچه. |
| چرخش کالا | Stock rotation — FIFO / FEFO | اول‌وارد اول‌خارج / اول‌انقضا اول‌خارج؛ کالای قدیمی‌تر جلو. |
| برچسب قیمت | Price tag / Shelf label | باید با قیمت صندوق یکی باشد (صحت قیمت). |

## ۳. اجرای میدانی (ویزیت و ممیزی)

| فارسی | English | توضیح کوتاه |
|---|---|---|
| ویزیت / بازدید | Visit / Call | حضور زمان‌دار یک نیرو در یک فروشگاه. |
| برنامهٔ مسیر | Route plan / Journey plan / Beat | کدام فروشگاه، چه روزی، با چه تناوبی. |
| پایبندی به برنامه | Journey-plan compliance | ویزیت‌های انجام‌شده ÷ ویزیت‌های برنامه‌ریزی‌شده. |
| ورود/خروج با موقعیت | Geo-fenced check-in / check-out | ثبت زمان و مختصات در شعاع مجاز فروشگاه. |
| عکس قبل/بعد | Before / After photo | شاهد تغییرات انجام‌شده در ویزیت. |
| ممیزی فروشگاه | Store audit / Retail audit | چک‌لیست ساخت‌یافته: موجودی، فیسینگ، قیمت، POSM، رقبا. |
| موجودی روی قفسه | On-Shelf Availability (OSA) | آیا SKU در لحظهٔ بازدید روی قفسه و در دسترس بود؟ |
| نبود کالا روی قفسه | Out-of-Stock (OOS) | مکمل OSA. |
| موجودی شبح | Phantom inventory | سیستم موجودی نشان می‌دهد ولی روی قفسه/انبار نیست. |
| فهرست کالای الزامی | Must-Stock List (MSL) / Core range | SKUهایی که هر فروشگاه (بسته به درجه) باید داشته باشد. |
| صحت قیمت | Price integrity / compliance | قیمت قفسه = قیمت مصوب/صندوق. |
| فروشگاه ایده‌آل | Perfect Store score | شاخص ترکیبی وزن‌دار از چند استاندارد اجرا. |
| سرعت رفع | Speed-to-fix | فاصلهٔ زمانی ثبت مشکل تا رفع آن. |
| درجه‌بندی فروشگاه | Outlet segmentation / grading (A/B/C) | تعیین تناوب ویزیت و MSL بر اساس پتانسیل و ریسک. |
| هزینهٔ خدمت‌دهی | Cost-to-serve | زمان، مسافت، تناوب و پیچیدگی خدمت‌دهی به یک فروشگاه. |
| کار / تسک ویزیت | Visit task | چیدن کالای جدید، ساخت دیسپلی، کنترل قیمت، نصب POSM. |
| پرسش‌نامه | Survey / Form | سؤالات ساخت‌یافته در ویزیت (با عکس اجباری در صورت نیاز). |

## ۴. برنامه‌ریزی کالا و قیمت

| فارسی | English | توضیح کوتاه |
|---|---|---|
| سبد کالا / تنوع کالا | Assortment / Range | کدام SKUها در کدام فروشگاه/کانال. |
| کد کالا | SKU (Stock Keeping Unit) | در این مخزن: `core.Item.sku`. |
| مدیریت طبقهٔ کالا | Category management | ادارهٔ هر دسته‌کالا مثل یک واحد کسب‌وکار (فرایند ۸ مرحله‌ای). |
| نقش دسته‌کالا | Category role: Destination / Routine / Seasonal / Convenience | مقصد / روزمره / فصلی / تکمیلی (خرید لحظه‌ای). |
| بودجهٔ مجاز خرید | Open-to-Buy (OTB) | چقدر هنوز می‌توان خرید کرد بی‌آنکه موجودی از برنامه بیرون بزند. |
| نرخ فروش‌رفت | Sell-through | واحد فروخته‌شده ÷ واحد در دسترس در دوره. |
| گردش موجودی | Stock turn / Inventory turnover | بهای تمام‌شده ÷ میانگین موجودی (به بها). |
| پوشش موجودی | Weeks / Days of supply (WOS/DOS) | موجودی فعلی با نرخ فروش فعلی چند هفته/روز دوام می‌آورد. |
| بازده سود ناخالص بر موجودی | GMROI | سود ناخالص ÷ میانگین موجودی به بها. |
| مارک‌آپ (افزایش روی بها) | Markup | سود ÷ بها. |
| حاشیهٔ سود ناخالص | Gross margin | سود ÷ قیمت فروش. |
| کاهش قیمت / تخفیف فصلی | Markdown | کاهش دائم یا موقت قیمت فروش. |
| مارک‌آپ اولیه / حفظ‌شده | IMU / MMU | قیمت‌گذاری اولیه با پیش‌بینی تخفیف‌ها / آنچه واقعاً ماند. |
| اتلاف / کسری | Shrinkage | تفاوت موجودی دفتری و فیزیکی (سرقت، خرابی، خطا). |

| برگشت از فروش و تخفیفات | Sales returns & allowances | — |
| تخفیف نقدی خرید / فروش | Purchase / Sales discount | — |
| هزینهٔ حمل به داخل | Freight-in | جزو بهای کالا (نه هزینهٔ دوره). |
| بازاریابی تجاری / هزینه‌های ترید | Trade marketing / Trade spend | هزینه‌های برند برای فروش از طریق کانال: تخفیف، دیسپلی، پروموشن، هزینهٔ ورود. |
