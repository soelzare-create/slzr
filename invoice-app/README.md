# داران‌ایکس — پیش‌فاکتور و فاکتور (وب‌اپ ساده)

یک برنامهٔ تحت وب سبک برای صدور **پیش‌فاکتور** و **فاکتور** با همان قالب برند داران‌ایکس، و
نگه‌داشتن **حساب بدهی مشتریان**. روی هر هاست اشتراکی معمولی (cPanel / DirectAdmin) با PHP
اجرا می‌شود و به دیتابیس MySQL یا نصب چیز دیگری نیاز ندارد. همهٔ اطلاعات در یک فایل
SQLite داخل پوشهٔ `data` ذخیره می‌شود.

## چه کارهایی انجام می‌دهد

- **پیش‌فاکتور و فاکتور روی همان قالب:** مستقیماً روی برگهٔ A4 تایپ می‌کنید: مشتری، اقلام،
  تعداد، قیمت، تخفیف، مالیات بر ارزش افزوده و توضیحات. جمع، مبلغ قابل پرداخت و «مبلغ به حروف»
  خودکار حساب می‌شوند. دکمهٔ **چاپ / PDF** همان برگه را چاپ می‌کند یا به‌صورت PDF ذخیره می‌کند.
- **شماره‌گذاری خودکار:** `QOT-0001` برای پیش‌فاکتور و `INV-0001` برای فاکتور. شماره قابل
  ویرایش هم هست.
- **تبدیل پیش‌فاکتور به فاکتور** با یک کلیک.
- **پیش‌فاکتور روی حساب مشتری اثری ندارد.** با صدور **فاکتور**، مشتری به اندازهٔ «قابل پرداخت»
  **بدهکار** می‌شود.
- **ثبت دریافت:** هر مبلغی که مشتری پرداخت کرد (کامل یا بخشی از بدهی) را ثبت می‌کنید و از
  بدهی او کم می‌شود. دریافت اشتباه را می‌توانید ویرایش یا حذف کنید.
- **صورت‌حساب هر مشتری:** فاکتورها (بدهکار)، دریافت‌ها (بستانکار) و مانده در هر ردیف. صورت‌حساب
  قابل چاپ است.
- **وضعیت پرداخت هر فاکتور:** «پرداخت‌نشده»، «مانده …» یا «تسویه‌شده». دریافت‌ها ابتدا
  قدیمی‌ترین بدهی را تسویه می‌کنند.
- **ابطال فاکتور:** مبلغ فاکتور از بدهی مشتری کم می‌شود. فاکتور باطل‌شده قابل بازگردانی است.
- **مانده از قبل:** برای مشتری‌ای که پیش از این برنامه بدهی یا طلب داشته.
- **داشبورد:** جمع طلب از مشتریان، فاکتورها و دریافتی‌های ماه جاری، و فهرست بدهکاران.
- **پشتیبان‌گیری:** از صفحهٔ تنظیمات با یک کلیک.
- ظاهر روشن و تیره، و سازگار با موبایل.

## پیش‌نیاز هاست

- PHP نسخهٔ **7.4 یا بالاتر** (8.x پیشنهاد می‌شود)
- افزونهٔ **pdo_sqlite** (روی بیشتر هاست‌ها به‌طور پیش‌فرض فعال است)
- Apache یا LiteSpeed (برای فایل‌های `.htaccess`). برای Nginx بخش «امنیت» را ببینید.

## نصب روی هاست و دامنهٔ daranx.com

۱. **ساخت ساب‌دامین:** در پنل هاست (cPanel → Domains یا Subdomains) یک ساب‌دامین بسازید، مثلاً
   `factor.daranx.com`. می‌توانید به‌جای آن یک پوشه داخل `public_html` بسازید (مثلاً
   `daranx.com/factor`). برنامه در هر دو حالت کار می‌کند.

۲. **آپلود:** فایل `daranx-invoice.zip` را از File Manager در **ریشهٔ همان ساب‌دامین** (یا همان
   پوشه) آپلود کنید و **Extract** بزنید. بعد از extract باید `index.php` و پوشه‌های `app`،
   `assets` و `data` مستقیماً در آن ریشه باشند. فایل‌های مخفی `.htaccess` هم باید وجود داشته
   باشند. در File Manager گزینهٔ «Show Hidden Files» را روشن کنید تا آن‌ها را ببینید.

۳. **نسخهٔ PHP:** در cPanel → «Select PHP Version» (یا «MultiPHP Manager») نسخهٔ 7.4 یا بالاتر را
   انتخاب کنید و مطمئن شوید تیک `pdo_sqlite` در بخش Extensions زده شده است.

۴. **دسترسی پوشهٔ data:** روی پوشهٔ `data` کلیک راست کنید و Permissions را روی **755** بگذارید.
   اگر برنامه خطای «قابل نوشتن نیست» داد، **775** را امتحان کنید.

۵. **SSL (حتماً):** از cPanel → «SSL/TLS Status» یا «Let's Encrypt» برای ساب‌دامین گواهی رایگان
   بگیرید. سپس در فایل `.htaccess` ریشه، چهار خط بخش HTTPS را از حالت کامنت خارج کنید (علامت `#`
   اول خط‌ها را بردارید) تا همیشه از `https://` باز شود.

۶. **راه‌اندازی اولیه:** آدرس را در مرورگر باز کنید (مثلاً `https://factor.daranx.com`). بار اول
   صفحهٔ «راه‌اندازی اولیه» باز می‌شود. یک نام کاربری (انگلیسی) و رمز عبور بسازید.
   ⚠️ این کار را **بلافاصله بعد از آپلود** انجام دهید، چون تا وقتی حسابی ساخته نشده، اولین کسی که
   آدرس را باز کند می‌تواند حساب را بسازد.

۷. **تنظیمات:** در صفحهٔ «تنظیمات» نام شرکت، شعار، تلفن‌ها، آدرس، وب‌سایت، درصد مالیات و متن
   پیش‌فرض «توضیحات» پیش‌فاکتور و فاکتور را بررسی کنید. این‌ها در سربرگ و پانویس اسناد چاپ
   می‌شوند.

## روش کار روزانه

| کار | کجا |
|---|---|
| پیش‌فاکتور جدید | منوی «پیش‌فاکتورها» ← «+ پیش‌فاکتور جدید». نام مشتری را بنویسید: اگر قبلاً ثبت شده باشد از فهرست انتخاب می‌شود و آدرس و تلفنش پر می‌شود، وگرنه با ذخیره خودکار ساخته می‌شود. |
| تبدیل به فاکتور | داخل پیش‌فاکتور ← «تبدیل به فاکتور». مبلغ به بدهی مشتری اضافه می‌شود. |
| فاکتور مستقیم | منوی «فاکتورها» ← «+ فاکتور جدید» ← «صدور فاکتور». |
| ثبت پرداخت مشتری | داخل فاکتور ← «ثبت دریافت»، یا منوی «دریافت‌ها». مبلغ، تاریخ و روش پرداخت را وارد کنید. |
| دیدن بدهی مشتری | منوی «مشتریان» ← نام مشتری (صورت‌حساب و دکمهٔ «چاپ صورت‌حساب»). |
| چاپ یا PDF | دکمهٔ «چاپ / PDF» در بالای هر سند. برای PDF در پنجرهٔ چاپ، مقصد را «Save as PDF» بگذارید. |
| ابطال فاکتور | داخل فاکتور ← منوی «⋯» ← «ابطال فاکتور». |

میانبر: در صفحهٔ سند، `Ctrl + S` ذخیره می‌کند.

## امنیت

- همهٔ صفحه‌ها به ورود نیاز دارند. بعد از ۵ رمز اشتباه، ورود ۱۵ دقیقه قفل می‌شود.
- پوشه‌های `app` و `data` با `.htaccess` از دسترس مستقیم بسته‌اند. نام فایل دیتابیس هم تصادفی
  است (`data/db_xxxxxxxx.sqlite`).
- **امن‌تر:** پوشهٔ داده را بیرون از `public_html` بگذارید. فایل `app/config.sample.php` را با نام
  `app/config.php` کپی کنید و مسیر `data_dir` را مثلاً روی `/home/USERNAME/daranx-data` تنظیم
  کنید.
- اگر سرور **Nginx** است، این قانون را به تنظیمات سایت اضافه کنید:

  ```nginx
  location ~ ^/(app|data)/ { deny all; }
  ```

## پشتیبان‌گیری و انتقال

- **پشتیبان:** «تنظیمات» ← «دانلود فایل پشتیبان». فایل دریافتی شامل همهٔ اطلاعات است. مرتب
  پشتیبان بگیرید.
- **بازگردانی یا انتقال به هاست دیگر:** برنامه را روی هاست جدید آپلود کنید. فایل پشتیبان را با
  نامی به شکل `db_backup.sqlite` (یعنی با پیشوند `db_` و پسوند `.sqlite`) داخل پوشهٔ `data`
  بگذارید. هر فایل `db_*.sqlite` دیگری را که آنجا هست پاک کنید.

## اجرا روی کامپیوتر برای امتحان

اگر PHP روی کامپیوترتان نصب است، داخل همین پوشه این دستور را بزنید و
`http://localhost:8000` را باز کنید:

```bash
php -S localhost:8000
```

## ساختار فایل‌ها

```
index.php          نقطهٔ ورود (همهٔ صفحه‌ها: index.php?p=…)
app/               کد برنامه (از دسترس وب بسته است)
  bootstrap.php    تنظیمات، نشست، هدرهای امنیتی
  db.php           ساخت و به‌روزرسانی خودکار جداول SQLite
  model.php        منطق: مشتری، سند، دریافت، محاسبهٔ مانده
  pages/           صفحه‌ها
assets/            ظاهر (رنگ‌ها و فونت Vazirmatn از قالب داران‌ایکس) و اسکریپت ویرایشگر برگه
data/              دیتابیس و نشست‌ها (ساخته می‌شود؛ از دسترس وب بسته است)
```
